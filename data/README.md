# 本地数据

`MNIST/raw/` 的 8 个原文件保持原位、名称和内容：训练/测试图像与标签，各有 gzip 压缩文件和解压文件，共 66,544,770 字节。这些是数据缓存，不是实验输出。

MNIST 代码通过 torchvision 使用 `root="./data"` 和 `download=True`。从仓库根目录启动可以使用这里的数据；从其他目录启动可能产生新的 data 目录。

本次没有新增 .gitignore，也没有提交数据。后续首次 Git 提交建议显式选择源码与文档，不把下载数据和包含本机路径的 VS Code 配置一起加入；可在单独的仓库配置步骤中添加忽略规则。
